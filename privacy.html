Trinos Record Privacy Policy

Effective date: 9 October 2026

1. Who we are

Trinos Record is a private macOS application operated by Trinos Strategy. It is used only by its owner. Contact: dk@trinos.group.

2. Google user data the app accesses

  • Gmail (gmail.send): used only to send an email that the user writes and confirms in the app. The app cannot read, list or delete any email.
  • Google Drive (drive.file): used only to upload files the user chooses and to create sharing permissions for the recipients the user names. The app can access only files it created itself.
  • Basic profile (openid, email): used only to show which account is signed in.

3. How the data is used and stored

  • All processing happens on the user's own Mac. Trinos Record has no server and does not send Google user data to Trinos Strategy or to any third party.
  • Sign-in tokens are stored only in the macOS Keychain of the user's Mac.
  • A local send log (date, sender, recipients, subject, file names and fingerprints, Gmail message ID, Drive file IDs) is kept only on the user's Mac. Email bodies are not stored.
  • Google user data is not used for advertising, profiling, model training or any purpose other than the user-requested send and share actions.

4. Sharing

Google user data is shared only with the recipients the user explicitly chooses for each email or Drive link. It is never sold or transferred.

5. Retention and deletion

The user can sign out in the app at any time; this revokes the token at Google and deletes it from the Keychain. Access can also be removed at myaccount.google.com/permissions. Deleting the app's data folder removes the local send log.

6. Limited Use

Trinos Record's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 한국어 요약

Trinos Record는 사용자 본인의 Mac에서만 동작하며 별도 서버가 없습니다. Gmail은 사용자가 확인한 메일을 보내는 데에만(읽기 불가), Google Drive는 앱이 만든 파일의 업로드와 공유에만 사용합니다. 로그인 토큰은 Mac의 키체인에만 저장되고, 보낸 기록은 본문 없이 Mac 안에만 남습니다. Google 사용자 데이터는 광고, 분석, 학습 등에 쓰지 않으며 사용자가 지정한 수신자 외에는 제공하지 않습니다. 앱에서 로그아웃하면 토큰이 폐기됩니다.

8. Changes

Changes to this policy are published on this page with a new effective date.
